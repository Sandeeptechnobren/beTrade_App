Critique a design output (mockup, draft screen, generated component) before accepting it.

1. Read `.claude/skills/frontend-design/SKILL.md` for the skill's invocation
2. Read `.claude/skills/frontend-design/reference/critique.md` for the critique reference
3. Read `.claude/skills/frontend-design/brand-context.md` if present
4. Apply the critique to the target. Watch for the default-template tells (Inter, system fonts, purple gradients, cards-in-cards, gray-on-color, bouncy animations).
5. Suggest concrete, opinionated alternatives — not generic "consider improving X".

Run on the **first output** from any AI design generation, before accepting.
